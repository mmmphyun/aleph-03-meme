## 2. 짧은 확인 방법 4줄 (T03-C31)

① **어디로 가나요:**
- 공개 배포 사이트인 `https://mmmphyun.github.io/aleph-03-meme/` 또는 소스 레포지토리 `https://github.com/mmmphyun/aleph-03-meme`로 이동합니다. (새 시크릿 창에서 계정 생성, 로그인, 비밀번호, OAuth 없이 즉시 열립니다.)

② **3단계 이내 무엇을 하나요:**
- 1) 좌측 사이드바 상단에서 화면비 버튼(`1:1`, `4:5`, `9:16`) 중 하나를 클릭합니다.
- 2) [내장 샘플 아트워크로 찢기]를 누르고 영역을 드래그한 뒤 [찢긴 조각 3D 추가]를 클릭합니다.
- 3) [고해상도 카드 다운로드] 버튼을 클릭합니다.

③ **무엇이 보이면 통과인가요:**
- 뷰포트의 뷰파인더 가이드 사각형 내부 구도(조명 그림자, 찢겨진 입체 단면, 한글 메모지 문구)와 100% 동일한 고해상도(1080p 규격) PNG 카드가 파일로 즉시 내려받아지면 통과입니다.

④ **안 될 때 무엇이 보이나요:**
- 지원하지 않는 파일(예: `.svg`, `.txt`)을 업로드하거나 문법이 손상된 JSON을 투입할 경우, 우측 상단에 빨간색 `[가져오기 거부]` 또는 `PNG 및 JPEG 파일만 지원합니다.` 에러 토스트가 뜨며, 기존에 작업 중이던 3D 씬과 레이어는 단 하나도 유실되지 않고 100% 원형 보존됩니다.

## 3. AI와 나의 판단 3줄 (T03-C32)

① **AI에게 맡긴 일:**
- Simplex/Perlin 노이즈 기반의 절차적 찢긴 종이(Torn Edge) 외곽선 생성 수학 공식 구현, Three.js ExtrudeGeometry 및 섀도 맵 조명 연동, JSON 3단계 검증기 및 Playwright 기반 12건 극단 입력 자동화 테스트 코드 작성을 위임했습니다.

② **학생이 직접 판단한 일:**
- 일반적인 2D 캔버스 합성 방식 대신 실제 빛과 종이 질감이 살아있는 3D 페이퍼 스컬프처 & 섀도 아트로 방향성을 확정하고, 인스타그램/SNS 피드 규격(1:1, 4:5, 9:16)에 맞춘 뷰파인더 클리핑 다운로드 파이프라인 및 극단 입력 시 기존 작업이 절대 유실되지 않는 'Fast-Fail & Zero-Mutation' 방어 설계를 직접 결정했습니다.

③ **AI 제안을 따르지 않은 일 (및 이유):**
- AI는 이미지 크롭 및 텍스처 추출 시 성능 최적화를 위해 CSS 마스킹과 가짜 2D 박스 섀도우를 사용할 것을 제안했으나, 종이 공예 특유의 깊이감 있는 3D 단면(Extrude + Bevel)과 다층 Z-Stack 간 실제 광원 지향성 그림자(DirectionalLight ShadowMap) 효과를 완벽하게 재현하기 위해 이를 반려하고 순수 Three.js WebGL 지오메트리 파이프라인을 고수했습니다.
