## 2. 짧은 확인 방법 4줄 (T03-C31)

① **어디로 가나요 (위치):**
- 공개 배포 사이트 `https://mmmphyun.github.io/aleph-03-meme/` 또는 로컬 호스트 `http://localhost:3030`으로 새 시크릿 창에서 이동합니다.

② **3단계 이내 무엇을 하나요 (행동):**
- 1) 좌측 사이드바에서 [내장 샘플 아트워크로 찢기]를 눌러 자유 올가미(Lasso)로 영역을 지정하고 [찢긴 조각 3D 추가]를 클릭합니다.
- 2) [텍스트 메모지 생성]을 누른 뒤 문구 입력창에 원하는 텍스트를 입력하거나 폰트 크기/색상을 조절합니다.
- 3) 화면비 버튼(`1:1`, `4:5`, `9:16`)을 선택한 뒤 [고해상도 카드 다운로드]를 클릭합니다.

③ **무엇이 보이면 통과인가요 (통과 모습):**
- 3D 섀도 박스 안의 뷰파인더 프레임 구도(오려낸 배경 구멍, 돌출된 팝업 조각의 입체 그림자, Pretendard 웹폰트로 깔끔하게 줄바꿈된 종이 메모지)와 100% 일치하는 1080p 고해상도 PNG 파일이 즉시 내려받아집니다.

④ **안 될 때 무엇이 보이나요 (안 될 때 모습):**
- 지원하지 않는 형식(`.svg`, `.txt` 등)의 파일을 드롭하거나 문법/필수 항목이 누락된 JSON을 투입할 경우, 상단에 빨간색 거부 토스트 알림이 출력되며 기존 3D 씬과 작업 레이어는 100% 원형 보존됩니다.

## 3. AI와 나의 판단 3줄 (T03-C32)

① **AI에게 맡긴 일:**
- Three.js 씬 및 섀도 박스 조명 연동, 절차적 찢김 외곽선 지오메트리 수식 구현, 템플릿 스토어 영속화 및 WebGL 텍스처 파이프라인 버그 디버깅을 위임했습니다.

② **학생이 직접 판단한 일:**
- 단일 사진을 배경과 오려낸 팝업 조각으로 입체화하는 3D 터널북 콘셉트를 확정하고, 불필요한 격자선 제거 및 Pretendard 표준 웹폰트 도입을 결정했으며, 토큰을 과소모하는 서브에이전트 남발을 중단시키고 직접 디버깅 방향을 통제했습니다.

③ **AI 제안을 따르지 않은 일 (및 이유):**
- AI는 텍스트 입력 길이에 맞춰 2D 캔버스 텍스처 해상도를 실시간으로 동적 리사이징하는 가변 버퍼 구조를 제안했으나, WebGL2 불변 텍스처 스토리지 충돌(`GL_INVALID_VALUE`) 및 메쉬의 극단적 세로 왜곡을 유발함을 확인하고 이를 반려한 뒤 최대 뷰포트 높이 제한 및 적응형 폰트 축소(Downscale) 아키텍처를 강제했습니다.
