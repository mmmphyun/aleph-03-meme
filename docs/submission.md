## 2. 짧은 확인 방법 4줄 (T03-C31)

1. **어디로 가나요 (위치)**:
   - 새 시크릿 창(Incognito)에서 배포 URL( https://mmmphyun.github.io/aleph-03-meme/ )로 접속합니다. (무로그인/무인증 즉시 접근)
2. **3단계 이내 무엇을 하나요 (행동)**:
   - ① 상단 화면비 툴바에서 [9:16] 버튼을 클릭하고 포즈 [최산 BAD]를 누릅니다.
   - ② 문구 입력창에 원하는 세레모니 문구를 입력하고 마우스로 3D 캐릭터 각도를 조절합니다.
   - ③ 하단의 [💾 고해상도 PNG 다운로드] 버튼을 클릭합니다.
3. **무엇이 보이면 통과인가요 (통과 모습)**:
   - 뷰포트에서 맞춘 3D 카메라 최종 앵글과 2D 문구가 100% 동일한 비례로 합성된 고해상도 PNG(1080×1920) 파일이 저장되고 정상적으로 열리면 통과입니다.
4. **안 될 때 무엇이 보이나요 (안 될 때 모습)**:
   - 다운로드된 이미지의 캐릭터 앵글이나 문구 줄바꿈이 화면과 불일치하거나, 지원하지 않는 파일(.txt)을 넣었을 때 에러 알림 없이 기존 화면이 백지화되면 실패입니다.

## 3. AI와 나의 판단 3줄 (T03-C32)

1. **AI에게 맡긴 일**:
   - Three.js 기반 3D 축구장 씬 렌더링, Daisy Bell 로우폴리 8각 인체 관절 계층 구조 빌드 및 챌린지 포즈(거제 야호, 최산 BAD, 호날두 시우 등)의 쿼터니언/오일러 회전 각도 산출, 극단 입력 12건 자동화 검증 스크립트 작성
2. **학생이 직접 판단한 일**:
   - 휘발성 유행어 프리셋을 전면 배제하고 사용자 자유도가 높은 순수 폼 컨트롤(내용/크기/색상/Y위치) 중심 인터페이스 설계, 1:1·4:5·9:16 세 화면비에서 화면 캔버스와 다운로드 파일의 100% 일치를 보장하는 오프스크린 2D 캔버스 합성 파이프라인 수립, 템플릿 손상을 원천 차단하는 JSON 3단계 사전 유효성 검증 정책 도입
3. **AI 제안을 따르지 않은 일(없으면 없었던 이유)**:
   - AI가 초기 제안한 무거운 외부 크롭 라이브러리(Cropper.js) 및 번들러(Webpack/Vite) 도입을 거부하고, 무의존성 경량화를 위해 순수 브라우저 Native Canvas 2D API 기반 타원 가이드 크롭 엔진과 순수 ES Modules 아키텍처를 고수함
