## 2. 결함 수정(FAIL -> PASS) 및 기술적 원인/조치 증적 (T03-C15)

극단 입력 12건 검사 수행 중 2건의 핵심 결함이 발견되어 즉각적인 아키텍처 개선 조치를 취했습니다.

### [결함 사례 1] 케이스 10: 초거대 폰트 크기(140px) 설정 시 상하 텍스트 클리핑 결함

- **검사 입력:** 폰트 크기 140px 설정 + 2줄 문구 입력 (`scripts/memo-label.js`)
- **수정 전 (FAIL):**
  - **현상:** 기존 슬라이더의 최대값이 76px로 하드코딩되어 있었으며, `MemoLabelEngine.setFontSize()` 역시 `Math.min(96, size)`로 클램핑되어 140px 설정이 불가능했음. 또한 140px 입력 시 1024x512 오프스크린 캔버스의 상하 높이를 초과하여 텍스트의 상단 및 하단이 잘려 나가는 시각적 결함 발생.
  - **증적 로그:** `[FAIL] MemoLabelEngine setFontSize(140) returned 96 (clamped). Text height exceeded canvas padding.`
- **기술적 원인 분석:**
  - `slider-font-size`의 HTML `max` 속성이 `76`으로 제한됨.
  - `setFontSize` 메소드 내 하드코딩된 가드(`Math.min(96, size)`).
  - 고정된 `lineHeight = Math.round(fontSize * 1.45)` 계산으로 인해 행간 합산 높이가 캔버스 가용 높이(432px)를 초과할 때 스케일 다운 피팅 알고리즘 부재.
- **수정 및 조치 내용:**
  1. `index.html`: `<input type="range" id="slider-font-size" min="12" max="140" step="2" value="42">`로 범위 확장.
  2. `scripts/memo-label.js`: `setFontSize(size)` 범위를 `Math.max(12, Math.min(140, size))`로 갱신.
  3. 적응형 텍스트 다운스케일 피팅 루프 구현:
     ```javascript
     // 140px 등 초거대 폰트나 다중 줄바꿈/긴 문장 시 캔버스 상하를 초과하지 않도록 적응형 스케일 다운
     let layout = layoutLines(fontSize);
     while (layout.totalHeight > maxTextHeight && fontSize > 14) {
       fontSize = Math.max(12, Math.floor(fontSize * 0.88));
       layout = layoutLines(fontSize);
     }
     ```
- **수정 후 (PASS):**
  - 140px 폰트 크기가 정상 수용되며, 문단 높이가 가용 영역을 초과할 경우 시각적 잘림 없이 캔버스 안에 완벽히 피팅되도록 자동 조정됨.

### [결함 사례 2] 케이스 08: 투명 배경 PNG 이미지 투입 시 검은 불투명 배경 렌더링 결함

- **검사 입력:** 알파 채널(투명도 0)을 포함하는 RGBA PNG 파일 크롭 및 3D 씬 추가
- **수정 전 (FAIL):**
  - **현상:** 투명 배경 PNG를 크롭하여 3D 조각으로 추가했을 때, 투명 영역이 투명하게 투과되지 않고 불투명한 미색 종이 바탕색(`0xf3efe6`)으로 덮여서 출력됨.
  - **증적 로그:** `[FAIL] latestLayer.material.transparent is false. Material rendered opaque background.`
- **기술적 원인 분석:**
  - `scripts/torn-geometry.js`의 `createTornPaperMesh`에서 머티리얼 생성 시 `transparent: true` 플래그가 누락되었으며, 기본 종이 컬러(`0xf3efe6`)가 텍스처와 곱연산(Multiply)되거나 알파 채널을 마스킹하지 못함.
- **수정 및 조치 내용:**
  1. `scripts/torn-geometry.js`: 텍스처(`materialOptions.map`)가 전달된 경우 베이스 컬러를 순백색(`0xffffff`)으로 설정하여 원본 발색을 보존하고, `transparent: Boolean(materialOptions.map)` 및 `alphaTest: 0.001`을 기본 부여하도록 개선.
  2. `scripts/app.js`: 크롭 데이터로부터 생성된 캔버스 텍스처가 WebGL 버퍼에서 투명 알파를 보존할 수 있도록 파이프라인 정비.
- **수정 후 (PASS):**
  - 투명 배경 PNG 조각이 3D 씬에서 배경 매트 보드와 하위 레이어를 완벽히 투과하며, 찢겨진 외곽선과 입체 그림자만 정상 투영됨 확인.

   - 투입 전 레이어 수: **5개** -> 투입 후 레이어 수: **5개** (0개 유실, 100% 보존).
